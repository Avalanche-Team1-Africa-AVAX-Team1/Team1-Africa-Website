**Format:** 5 value blocks
**Each block contains:**
- **Value Name** (1-2 words, capitalized)
- **Description** (1 sentence, 60-100 characters)

**Required Values for Team1:**
1. **Alignment** — Focus on shared direction
2. **Accountability** — Ownership and delivery
3. **Respect** — Diversity and inclusion

## SECTION 6: TIMELINE / JOURNEY

**Format:** 4-6 milestone entries
**Each entry contains:**
- **Year** (YYYY format)
- **Event Title** (2-4 words, title case)
- **Description** (1 sentence, 80-120 characters)

**Milestone Types to Include:**
- Foundation/inception
- Key expansion moments
- Major achievements (events, developers, projects)
- Framework/process implementations
- Future vision/goals

**Writing Guidelines:**
- Use past tense for historical events
- Use present/future tense for ongoing/upcoming
- Be specific with numbers when possible
- Keep parallel structure

**Example:**
```
{
  "year": "2022",
  "event": "Regional Expansion",
  "description": "Launched regional teams in Africa, Asia, and Latin America with standardized frameworks."
}
```

### Alt Text Guidelines
**Format:** [Full Name], [Role] for [Organization/Region]
**Length:** 50-90 characters
**Style:** Descriptive, specific, accessible

**Examples:**
- "Adewale Ogunlesi, Team1 Africa Nigeria Regional Lead"
- "Chinara Eze, Developer Advocate for Team1 Africa Nigeria"
- "Kwame Mensah, Team1 Africa Ghana Regional Lead"

**Alt Text Best Practices:**
- Include full name exactly as displayed
- Include complete role title
- Include organization and region for context
- Avoid "picture of" or "photo of"
- Use natural language structure
